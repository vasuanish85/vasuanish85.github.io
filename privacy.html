Privacy Policy — Vasu Brain

Last updated: 8 October 2026

Vasu Brain is a personal tool used only by its owner. It accesses only the owner's own Google account.

Data accessed

  • Gmail messages (read-only)
  • Google Calendar events (read-only)
  • Google Drive file metadata and content (read-only)

How data is used

Data is processed on the owner's personal computer to produce private notes and daily summaries. Text is sent to Anthropic's Claude API solely to generate those summaries. Outputs are stored locally on the owner's computer.

Sharing

Data is not sold, shared with third parties for any other purpose, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
